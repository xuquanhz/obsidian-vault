# 📥 待处理清单

> 收件箱里还没处理的条目。清空即今日闭环完成。

## 全部待处理

```dataview
TABLE file.ctime AS "放入时间", status AS "状态"
FROM "收件箱"
WHERE file.name != "收件箱说明" AND file.name != "待处理清单"
SORT file.ctime DESC
```

## 超过 7 天未处理（优先销毁判断）

```dataview
LIST
FROM "收件箱"
WHERE file.name != "收件箱说明" AND file.name != "待处理清单"
  AND file.mtime < date(today) - dur(7 days)
SORT file.mtime ASC
```
