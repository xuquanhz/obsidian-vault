# 📥 收件箱

> 知识库的**唯一入口**。任何新东西先进这里，不要直接丢进 `工作/`、`书籍/`、`豆包视频解读/`。

## 三条硬规则

1. **只收集，不整理**——存进来时不要重命名、不要分类、不要写摘要。整理是"处理"环节的事。
2. **24 小时内必处理**——要么提炼成知识条目归档，要么判定无价值直接删除。收件箱不允许堆积。
3. **每条只能被处理一次**——处理后移出收件箱（或标 `status: done`），不在收件箱里留"半成品"。

## 怎么放进来

| 来源 | 做法 |
|:--|:--|
| 网页文章 | Obsidian Web Clipper 一键剪藏，落到 `收件箱/` |
| 微信/聊天里的干货 | 手机复制 → fast-note-sync 或 wechat-obsync 同步进来 |
| 抖音/视频 | 先写一行链接 + 一句"为什么值得存"（配套模板：`模板/收件速记.md`） |
| 会议、临时想法 | `Ctrl+N` → 用「收件速记」模板，30 秒记完 |
| 文件（PDF/Word/图片） | 附件同放 `收件箱/`，正文写一句来源与用途 |

## 处理动作（每条的三种去向）

处理时使用 `模板/知识条目.md` 生成正式笔记，然后：

- → **进分区**：`工作/`、`书籍/`、`提示词/`、`个人资料/` 等，并更新该分区 MOC
- → **进产出**：素材够支撑一篇判断/报告，直接写成 `产出/` 里的成果，再回流链接
- → **销毁**：看完发现没价值，直接删。收件箱里没有"以后可能有用"

## 处理节奏

- 日常：每天打开 `工作台.md`，收件箱有货就清空
- 批量：每周集中处理一次，超过 7 天未动的条目优先做"销毁"判断——**留着不处理比删掉更糟**
