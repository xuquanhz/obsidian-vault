# 📜 照片做旧 · 复古明信片质感提示词

> 把任意画面（国画、照片、插画）"印"到一张有年代感的旧明信片上。核心是三件事：**纸要旧、卡要浮、戳要淡**。做旧是载体层，不能吃掉画面主体。

## 一、完整原文（可直接复制）

将这幅作品印刷在一张复古老旧纸质明信片上，整体呈现真实年代收藏感。明信片纸张深度泛黄，自带天然粗糙纸纤维质感，边缘不规则毛边、多处磨损痕迹、深浅交错的复古折痕，局部布满自然岁月纸斑、老旧压痕，整体纸张褶皱感大幅强化，有自然凹凸起伏的老旧纸质肌理，一角自然折角，岁月沧桑质感浓郁。明信片微微悬浮在纯色背景之上，带有柔和淡淡的投影，营造浮于纸面的立体感。明信片角落加盖一枚模糊复古黑色邮戳，邮戳半透明不破坏主体与题跋区域，文字区域保持干净清晰、完整可辨。色彩克制简约，整体低饱和、朦胧、柔和。

❌ 禁止：现代边框、塑料质感、数码锐化、过度脏污掩盖画面主体、强烈硬阴影、鲜艳高饱和色彩、机械排版、水印感。

## 二、结构拆解（四段式）

| 段 | 作用 | 关键措辞 |
|:--|:--|:--|
| ① 定调 | 说明这是"印刷在明信片上"，不是画在纸上 | 印刷在、年代收藏感 |
| ② 纸张老化 | 泛黄、纤维、毛边、磨损、折痕、纸斑、压痕、折角 | 深度泛黄 / 天然粗糙纸纤维 / 不规则毛边 / 深浅交错折痕 / 自然岁月纸斑 / 一角自然折角 |
| ③ 空间关系 | 悬浮 + 投影，制造"实物感" | 微微悬浮在纯色背景之上 / 柔和淡淡的投影 / 浮于纸面的立体感 |
| ④ 邮戳 | 点睛，且必须让位主体 | 模糊复古黑色邮戳 / 半透明 / 不破坏主体与题跋 / 文字区域干净可辨 |

## 三、常用参数（ImageGen）

| 参数 | 建议值 | 说明 |
|:--|:--|:--|
| `input_fidelity` | `high` | 做旧是叠加层，必须锁住底图构图与主体 |
| `size` | 竖版 `1024x1536` / 横版 `1536x1024` | 跟随底图比例，别强行改画幅 |
| `quality` | `high` | 纸张纤维、纸斑细节靠它 |
| 输出后处理 | 抹右下角"AI生成"水印 | 模型会自己烙，提示词里写"禁止水印"无效，必须出图后修（`remove-watermark`，区域 `0.85,0.93,0.15,0.07`） |

## 四、使用要点（踩过的坑）

1. **做旧强度要分级**：轻做旧（轻微泛黄+一处折角）、中做旧（毛边+纸斑+邮戳）、重做旧（褶皱+压痕+破损）。默认用中做旧，重做旧容易吃掉画面细节。
2. **邮戳位置避开题跋**：明确写"不破坏题跋区域"，否则模型会把邮戳压在书法上，字就废了。
3. **"悬浮+投影"需要纯色背景**：如果底图本身有复杂背景，先把背景改成纯色（米白/浅灰）再说，否则出不来"浮于纸面"的效果。
4. **别让脏污盖主体**：负面清单里"过度脏污掩盖画面主体"这条必留，模型很容易把纸斑糊到人脸/题跋上。
5. **与画种风格叠加时**：做旧段放在风格段之后、禁止清单之前，顺序错了会被当成"画在旧纸上"而不是"印在明信片上"。

## 五、变体：单张老照片做旧（非明信片）

如果目标不是明信片，而是"一张放了三十年的老照片"，把第②③④段替换为：

照片呈现银盐相纸自然老化质感：整体泛黄偏暖，高光轻微褪色、暗部略泛褐，边缘有细微磨损与卷曲，表面散布少量灰尘颗粒与细微划痕，四角轻微圆钝，画面中央保持清晰完整、不受污渍遮挡。禁止：做旧过度导致细节丢失、明显破洞、大面积霉斑、现代相框。
