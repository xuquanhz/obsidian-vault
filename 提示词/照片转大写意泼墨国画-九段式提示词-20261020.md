# 🖌 照片转大写意泼墨国画 · 九段式提示词

> 把任意照片整体转译成中国大写意大泼墨国画，再"印"到复古老明信片上。核心不是画得像，而是**保住构图、抽掉细节、留下气韵**。

## 一、完整原文（可直接复制）

将目标画面整体转译为中国大写意大泼墨国画风格，严格保留原图整体构图、主体物体位置、画面结构、空间层级、光影明暗关系与主要色彩来源，不改变原有画面布局。以阔笔泼墨、湿墨破墨结合写意线条，重在提炼物象神韵，摒弃写实细节刻画，不描摹物体局部细节，只概括轮廓、动势、体量与虚实关系。

前景细碎物象如枝叶、花草、柳条等，避免具象单片叶子、花瓣和针状细节，改用墨点、短线、断笔、飞白笔触、干湿变化线组和符号化墨块表现；只抓取整体动势、疏密聚散与墨色节奏，不让前景停留在植物学细节上。中景以泼墨块面概括，远景以淡墨晕染消融，虚实相生，远虚近略实，保持大面积透气留白。

墨色层次须包含焦、浓、重、淡、清五色变化，水墨在宣纸上自然洇染、渗化、晕开，保留宣纸纤维肌理与湿墨边缘。画面构图遵循中国画虚实、疏密、开合、留白关系，主体不宜堆满画面，远景宜淡、宜散、宜融，前景宜略收、宜有墨骨、宜形成节奏。

在画面合适留白处加入传统中国书法题跋，书法采用古韵洒脱草书字体，笔意连绵灵动、气韵奔放潇洒，笔画有牵丝飞白、虚实变化，书写自然随性、错落有致，墨色浓淡层次丰富，字距疏密错落，题跋内容贴合湖山暮色意境；题字须与画面气韵深度融合，成为构图的一部分，而非额外贴图。题跋旁加入朱红篆刻印章，印章边缘略有印泥渗化，位置在画面边角落款旁，尺寸克制，起到点睛平衡作用。

将这幅国画作品印刷在一张复古老旧纸质明信片上，整体呈现真实年代收藏感。明信片纸张深度泛黄，自带天然粗糙纸纤维质感，边缘不规则毛边、多处磨损痕迹、深浅交错的复古折痕，局部布满自然岁月纸斑、老旧压痕，整体纸张褶皱感大幅强化，有自然凹凸起伏的老旧纸质肌理，一角自然折角，岁月沧桑质感浓郁。明信片微微悬浮在纯色背景之上，带有柔和淡淡的投影，营造浮于纸面的立体感。明信片角落加盖一枚模糊复古黑色邮戳，邮戳半透明不破坏国画主体与题跋区域，题跋文字区域保持干净清晰、完整可辨。

色彩克制简约，国画部分仅保留画面原有少量淡色信息，如淡霞光、淡青灰、淡赭石等，其余以黑白水墨为主，整体低饱和、朦胧、柔和。笔触奔放洒脱，追求气韵、意境和文人画氛围，物象边缘自然渗化，无生硬锐利轮廓。

❌ 禁止：写实摄影质感、照片质感、3D渲染、厚涂油画、精细刻画、清晰硬轮廓、鲜艳高饱和色彩、强烈硬阴影、塑料质感、数码锐化、复杂纹理、多余杂物、人物五官特写、现代边框、水印感、机械排版、过度脏污掩盖国画画面。

## 二、结构拆解（九段式）

| # | 段 | 管什么 | 不改会怎样 |
|:--|:--|:--|:--|
| ① | 整体转译 + 锁构图 | 构图、主体位置、空间层级、明暗关系、"不改变布局" | 模型自由重绘，构图漂移 |
| ② | 技法语言 | 阔笔泼墨、湿墨破墨、写意线条、只取轮廓动势体量 | 滑向写实或插画感 |
| ③ | 前景处理 | 枝叶花草一律墨点/短线/断笔/飞白，禁止植物学细节 | 前景变工笔，抢主体 |
| ④ | 中景 + 远景 | 中景块面概括、远景淡墨晕染消融、远虚近略实、大面积留白 | 画面堵死，没有空气感 |
| ⑤ | 墨色 + 构图原则 | 焦浓重淡清五色、宣纸洇渗、虚实疏密开合留白 | 墨色平、像黑白照片加滤镜 |
| ⑥ | 题跋 + 印章 | 草书、牵丝飞白、贴合意境、朱红篆印、尺寸克制 | 题跋像贴纸，或者字糊成乱码 |
| ⑦ | 载体（明信片） | 泛黄、纸纤维、毛边、折痕、纸斑、折角、悬浮投影、半透明邮戳 | 少了"实物感"，只是张图 |
| ⑧ | 色彩 + 笔触 | 只留淡霞/淡青灰/淡赭石，其余黑白；低饱和朦胧 | 出来像彩墨或水彩 |
| ⑨ | 禁止清单 | 17 项负面约束 | AI 味压不住 |

## 三、ImageGen 参数

| 参数 | 建议值 | 说明 |
|:--|:--|:--|
| `image1` | 底图路径 | 必须图生图，纯文生图锁不住构图 |
| `input_fidelity` | `high` | 最关键的一个参数，medium 以下构图必飘 |
| `size` | 跟随底图（竖 1024×1536 / 横 1536×1024 / 方 1024×1024） | 改比例等于改构图 |
| `quality` | `high` | 纸纤维、墨韵细节靠它 |
| `style` | `Chinese xieyi splash-ink painting on aged postcard` | 英文只作风格提示，主体靠中文prompt |
| 出图后 | 抹右下角"AI生成"水印 | `remove-watermark --region 0.85,0.93,0.15,0.07` |

## 四、场景补丁（原文按需替换这几处）

**1. 题跋内容**——原文写"贴合湖山暮色意境"，换场景必须整句替换，否则题跋文不对题：
- 山水湖景：湖山暮色入帘青，月满中秋夜色明
- 市井人物：窗畔闲坐观市声，杯盏烟火暖浮生
- 古建园林：飞檐承露苔痕老，一树秋光落瓦当

**2. 前景物象**——原文举例"枝叶、花草、柳条"，拍的是餐桌/街景要改成"餐具、杯盏、纸巾、桌椅"等，否则模型会硬塞几根柳条进去。

**3. 人物场景必加一句**——原文只写"人物五官特写"在禁止清单里，不够。要在②段后补：
> 人物只概括身姿动势、体量与虚实关系，不刻画五官细节与皮肤纹理。

**4. 不要明信片载体**——删掉⑦段和第⑨段里的"现代边框"，改成"作品直接呈现于宣纸之上，四周留白"。

**5. 换画种**——只动三处：②段技法词汇、⑥段人文元素、⑨段禁止清单。浮世绘版就是把"泼墨破墨"换成"木刻套色+ぼかし"，题跋换成画赞+雅号印。这个框架已实测可迁到浮世绘、蓝晒、泥金手抄本。

## 六、三条硬经验

1. **`input_fidelity=high` 是这个框架的地基**，调低一档构图就开始漂，人物会换姿势。
2. **题跋是唯一容易翻车的地方**：中文草书在图生图里靠底图锚点才准，纯文生图十次有八次是乱码。底图没有文字残留时，宁可让题跋短一点。
3. **禁止清单不能省**，尤其"写实摄影质感/数码锐化/塑料质感"这三条，删了立刻出 AI 味。
