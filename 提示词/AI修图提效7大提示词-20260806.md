## 1. 光效渲染

提示词：

```
严格锁定主体外轮廓与原始暗调背景，一键激活X光深层透视渲染模型，将产品外壳转化为半透明的黑透材质，清晰显露内部精密的散热铜管与电路结构。在三个风扇核心处注入极具能量感的霓虹红双态动态光效（如电光蓝与核心橙），并在风扇周围生成符合空气动力学的悬浮发光粒子与高速旋转的光晕拉丝，呈现极具侵略性的硬核赛博状态。
```

## 2. 一键转手绘线

提示词：

```
智能提取目标物体的空间透视与三维轮廓，一键转化为极具机械美感的工业设计黑白概念线稿。精准勾勒复杂的空气动力学边缘、机械传动部件与装配接缝。在背景自动生成专业的流体力学辅助线、透视网格及尺寸标注排版。采用精准的马克笔笔触与轻微的灰阶排线表现截面体积，量现顶级工业设计师的手绘蓝图质感。
```

## 3. 一键消除

提示词：

```
智能识别并彻底抹除画面中的破坏性杂物及其投射的混乱阴影。激活AI像素级重建算法，深度解析并完美延展被遮挡的复杂背景（如高难度几何印花、编织纹理等）。强制对齐全局光照逻辑，无缝重建断裂的环境光影（如百叶窗投影），确保填补区域与原始画面在纹理、透视与光照上达成100%的物理级统一，拒绝任何PS涂抹痕迹。
```

## 4. 一键无损放大

提示词：

```
将此图像修复并增强为清晰、高分辨率的逼真照片。保留原图所有核心元素主体身份、面部特征、表情、姿态、构图、视角、服装、背景及光影氛围。以自然真实的手法提升细节、分辨率、质感与整体清晰度。修复模糊、噪点、压缩画质损耗、象素化、细节灰皮及画面偏软等问题。在不改变原图内容的基础上，还还原真皮的皮肤纹理、毛发细节、眼部高光、织物材质及背景元素。保持色彩自然，对亮度真实细节符合物理逻辑。严禁过度处理、过度磨皮、美颜滤镜感、AI题造特征。
```

## 5. 一键融图

提示词：

```
精准提取目标产品并无缝置入新场景。强制启用全局光照(GI)计算，完美吸收环境双光源(如冷蓝光与暖橙光)形成立体反射。真实演算玻璃材质的透光率与折射率，并在承接面上投射带有液体色彩的物理焦散阴影(Caustics)，彻底消除边缘抠图感，实现电影级空间光影融合。
```

## 6. 精修产品

提示词：

```
将主体置于纯白无缝背景中，利用3D渲染光影重塑其初始材质(如高级皮革的哑光纹理、塑料组件的镜面反光)。一键抹除所有物理磨损、泥土污渍与岁月痕迹，恢复至全新出厂状态。强化立体光感与阴影过渡，提升整体商业精致度，直出符合顶配电商主图的标准图像。
```

## 7. 一键风格复刻

提示词：

```
提取参考图的环境特效与空间深度遮挡Mask(蒙版)。将目标产品完美替换入特效中心，强制保留原始流体/烟雾对主体的前景遮挡关系。重构产品表面光线折射模型，使其100%匹配新场景的复杂环境光(如金属反光、丝绸漫反射)，实现特效与实物的像素级物理融合。
```
