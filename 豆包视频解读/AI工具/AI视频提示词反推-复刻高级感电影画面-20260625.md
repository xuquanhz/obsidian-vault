# AI视频提示词反推 — 复刻高级感电影画面

## 核心思路

看到一条高质量 AI 视频，想复刻它的电影感画面？不用猜提示词——直接用 AI **反推**出原视频的提示词，再根据自己的需求微调即可。

---

## 方法一：Gemini AI Studio 反推法（推荐⭐）

**来源**：国外博主 AIWarper（x.com/AIWarper），被国内多位 AI 博主验证有效。

### 操作步骤

| 步骤 | 操作 |
|------|------|
| 1 | **下载原视频** — 把你想要反推的 AI 视频保存到本地 |
| 2 | **打开 Google AI Studio** — 访问 [aistudio.google.com](https://aistudio.google.com)，模型选择 **Gemini 3.1 Pro Preview**（或最新 Pro 版） |
| 3 | **粘贴系统指令** — 将系统指令粘贴到 AI Studio 的「System Instructions」框中（👉 指令来源：`pastebin.com/H8DeXq1G`） |
| 4 | **上传视频** — 上传第一步下载的视频 |
| 5 | **输入指令** — 在对话框中输入：`follow your system instructions` |
| 6 | **获取结果** — Gemini 自动拆解视频，输出分镜级别的结构化描述（JSON 格式），包含运镜方式、画面内容、角色动作、视觉特效、环境氛围等 |
| 7 | **生成视频** — 将反推出的提示词导入 Seedance、可灵、Sora 等工具即可 |

> 💡 **微调技巧**：拿到 Gemini 输出的分镜 JSON 后，可用豆包等工具合成完整提示词，再根据需要修改画面元素。

## 方法二：专用反推工具

### VideoFlow（videoflow.cc）
- 支持粘贴**抖音/小红书/B站链接**直接解析
- 自动识别镜头切换，输出逐镜画面、运镜、台词、完整剧本
- 已开放 **API 和 MCP 接入**，可集成到工作流

### promptvv.com
- 支持抖音/小红书/B站链接直接解析
- 生成的提示词可直接喂给 **Seedance、可灵** 等视频模型
- 注册送 30 秒免费额度

### 可灵AI 内置方案
组合使用三步法：
1. 用截图反推单帧提示词
2. 用 promptvv 自动拆解整条视频
3. 用可灵内置 **DeepSeek-R1** 智能扩写提示词

## 方法三：豆包AI 万能反推模板

来源：抖音博主 @团子讲AI

只需一条指令，要求模型输出必须包含：

| 要素 | 说明 |
|------|------|
| **主体描述** | 核心对象特征、动作精确说明、动态表现 |
| **场景环境** | 时间设定（晨/午/黄昏/夜）、光影类型/强度/方向 |
| **运镜方式** | 推/拉/摇/移、俯拍/仰拍、手持/稳定 |
| **镜头语言** | 构图方式、景别（特写/中景/远景） |
| **色调风格** | 冷暖调、饱和度、色彩倾向 |
| **画质参数** | 分辨率、帧率、颗粒感等 |

## 复刻「高级感/电影感」的关键技巧

> ⚠️ 高级感 ≠ 空泛描述。必须从具体视觉元素入手。

### 轻奢商业广告感
- **低对比色彩** + 干净背景 + 侧向柔光
- 明确描述服装材质、配色、光线方向

### 电影感增强叠加公式
```
运动设计 + 电影运镜 + 色彩分级 + 动态节奏
```

### 具体 Checklist

| 维度 | 需要明确的关键词 |
|------|------------------|
| 光影 | 侧光、逆光、柔光、硬光、黄金时刻、蓝调时刻、伦勃朗光 |
| 色彩 | 低饱和度、胶片颗粒、Teal & Orange、褪色感 |
| 运镜 | 缓慢推镜（slow push-in）、轨道平移（dolly）、手持微晃 |
| 构图 | 三分法、引导线、负空间、对称构图 |
| 景深 | 浅景深（f/1.4）、虚化背景、焦外光斑 |
| 质感 | 35mm胶片、8mm复古、电影宽银幕（2.39:1）、颗粒感 |

## 提示词模板示例

### 反推指令模板（豆包风格）
```
请分析这段视频，输出以下内容：
1. 主体：详细描述画面中的核心对象（外观、材质、动作）
2. 场景：时间、地点、环境细节
3. 光线：光源方向、强度、色温、阴影特征
4. 运镜：镜头运动方式、速度、节奏
5. 色彩：主色调、饱和度、对比度
6. 画质：分辨率、宽高比、特殊效果
7. 可直接使用的AI视频生成提示词
```
