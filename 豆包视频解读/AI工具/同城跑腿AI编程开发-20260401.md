# AI 编程开发同城跑腿系统（零基础保姆级教程）

从零开发同城跑腿系统，涵盖多端应用协同开发。

---

## 一、开发流程概述

1. **UI 与原型图设计** → 使用 AI 设计神器 stitch 生成 UI 设计草稿和原型图
2. **项目初始化** → 安装 HBuilderX、AI 编程工具等
3. **前端开发** → 利用 AI 开发工具将原型图转化为代码
4. **后端开发** → AI 设计数据库，云函数实现多端联动
5. **后台管理 + 多端发布** → uni-app 打包发布

## 二、关键步骤详解

### 项目初始化与环境配置
- 下载 HBuilderX、AI 编程工具、小程序开发者工具
- 在 HBuilderX 中创建用户端和骑手端项目
- 启用 unicloud 并关联阿里云服务空间
- 注册微信服务号和小程序，配置应用 ID

### UI 与原型图生成（stitch）
- 提示词示例："开发同城跑腿小程序用户端 UI，底部导航栏有'预约''订单''我的'三个根页面，界面中文，主题蓝白色为主"
- 选 AI 模型（如 Gemini 3 Flash）生成 UI 草稿图
- 草稿图可模块化编辑后一键转化为原型图及 HTML、CSS 代码

### 前后端开发与数据联动
- **前端**：原型图代码导入 AI 开发工具，生成可交互前端页面
- **后端**：设计数据库，开发云函数实现用户端与骑手端的订单数据同步

### 后台管理系统与多端发布
- 开发后台管理系统管理订单、用户、骑手
- 通过 uni-app 打包发布为微信、抖音小程序以及苹果、安卓应用
- 一套代码多端运行

## 三、最终效果

- 用户端下单 → 骑手端抢单 → 订单状态实时同步 → 后台管理
- 一套代码同时适配微信、抖音小程序以及苹果、安卓应用
