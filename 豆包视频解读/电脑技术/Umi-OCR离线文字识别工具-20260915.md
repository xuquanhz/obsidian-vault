# Umi-OCR 离线文字识别工具

> **结论**：值得装。MIT 开源、解压即用、全程离线，中文识别够用。真正的强项是 **截图 OCR + 批量图片 + 扫描版 PDF 转「双层可搜索 PDF」**。
>
> **但视频里有两处口径不实**：① 它**不能**做表格结构化识别（官方还把它列在"远期计划"里）；② 导出格式里**没有 DOCX / XLSX**。详见第三节。

## 二、核心功能（以官方 README 的五个标签页为准）

### 1. 截图 OCR

- 全局快捷键唤起截图，识别结果进右侧记录栏，可直接编辑、划选复制
- 左侧图片预览栏可用鼠标**直接划选复制**图中文字
- 支持在别处复制图片后粘贴进 Umi-OCR 识别
- 自带**文本后处理（排版解析）**：按正确阅读顺序输出文字，避免格式错乱
- 含**公式识别**（图片里的数学公式转 LaTeX）

### 2. 批量 OCR

- 支持格式：`jpg / jpe / jpeg / jfif / png / webp / bmp / tif / tiff`
- **保存结果格式：`txt / jsonl / md / csv(Excel)`**
- 无数量上限，可一次导入几百张图
- 支持任务完成后**自动关机 / 待机**
- 特殊功能 **「忽略区域」**：排除截图水印处的文字

### 3. 文档识别（PDF）

- 支持格式：`pdf / xps / epub / mobi / fb2 / cbz`
- 扫描件 OCR，或提取原有文本层
- 可输出为 **双层可搜索 PDF**（原图 + 可复制文字层）
- 可设**忽略区域**排除页眉页脚

### 4. 二维码

- 扫码：截图 / 粘贴 / 拖入图片，读取二维码、条形码，支持**一图多码**
- 生成码：输入文本生成二维码图片
- 支持 19 种协议（Aztec、Code128、Code39、DataMatrix、EAN13/8、PDF417、QRCode、UPCA 等）

### 5. 全局设置

- 一键创建快捷方式、设置开机自启
- 切换界面语言 / 主题（亮暗）/ 字号字体
- 切换 OCR 插件
- **渲染器设置**：默认开启显卡加速；若出现截图闪烁、UI 错位，切到其他渲染方案或关闭硬件加速

## 三、视频口径 vs 官方核实（重要）

| 视频说法 | 核实结果 | 判断 |
|:--|:--|:--:|
| 支持截图识别、格式不错乱 | 确认，靠「文本后处理 / 排版解析」实现 | ✅ |
| 支持**表格识别** | 官方 README 的**「远期计划」**里仍列着「识别表格图片，输出为 Excel」——即**尚未实现**。截图 OCR 能把含表格图片里的**文字**按排版提取出来，但**不是**表格结构还原 | ❌ **纠正** |
| 可识别身份证、银行卡、驾驶证、营业执照、发票、快递单、车牌等**专项证件** | 官方 README 未提任何证件模板/专项模型，官方定位是**通用 OCR + 多语言库**。通用 OCR 确实能识别这些图片上的文字，但**没有结构化字段提取**（不会自动拆出"姓名/证件号/有效期"） | ⚠️ **夸大** |
| 导出 **CSV / DOCX / XLSX** | 官方明确只有 `txt / jsonl / md / csv(Excel)` 四种。**没有 DOCX、没有 XLSX**（csv 可用 Excel 打开） | ⚠️ **部分失实** |
| 软件本体 **43.1MB**、占用不到 100MB | 官方 FAQ：约需 200MB 磁盘空间；Paddle 版模型约 128MB、Rapid 版约 97MB。43.1MB 未获官方确认，可能是某个压缩包体积 | ⚠️ **待核** |
| 免费开源、离线运行、不上传数据 | 确认，MIT 协议，识别全部在本地完成 | ✅ |
| 批量导入、处理快、无数量限制 | 确认 | ✅ |
| 快捷键一键唤起 | 确认有全局快捷键机制（默认键位官方 README 未注明，可在设置里自定义） | ✅ |

## 四、上手三步

1. **下载解压**：github.com/hiroi-sora/Umi-OCR/releases（或蓝奏云 / Source Forge），绿色免安装，解压到任意目录
   - 也可用 Scoop：`scoop install extras/umi-ocr`（Rapid 引擎）/ `extras/umi-ocr-paddle`（Paddle 引擎），**两者不要同时装**
2. **选引擎**：追求精度选 Paddle，追求速度选 Rapid
3. **干活**：截图 OCR（快捷键）/ 批量 OCR（导入图片）/ 文档识别（导入 PDF）

> **渲染器提示**：老机器或远控环境下如果截图闪烁、界面错位，去「全局设置 → 界面和外观 → 渲染器」换成别的方案或关闭硬件加速。

## 五、对你手上的事能直接用在哪

| 场景 | 用法 |
|:--|:--|
| E 类人才材料里的扫描件 PDF（社保证明、劳动合同、银行流水） | 用「文档识别」转**双层可搜索 PDF**，之后能全文搜索、也能被 AI 读取 |
| 合同扫描件、审计报告、制度原件 | 同上，转成可检索 PDF 后归档，比纯图片更可追溯 |
| 微信 / 钉钉里收到的截图（通知、报价、聊天记录） | 截图 OCR 直接取字，不用手打 |
| 一沓拍照收集的表单 | 批量 OCR 一次导入，导出 csv 汇总 |
| 需要去掉水印 / 页眉页脚干扰的批量图 | 「忽略区域」框掉后再识别 |

## 六、注意事项

- **表格还原、表格转 Excel 目前都不支持**，不要指望拿它做表格数字化；需要表格结构请另找工具
- 导出**不支持 DOCX / XLSX**，只能 txt / jsonl / md / csv
- 首次使用需下载模型文件，**模型下载完成后**才能完全离线运行
- 官方把「MacOS / Ubuntu 支持」「图片翻译」「文本纠错」「历史记录系统」等都列在**远期计划**，现在还没有
- 有 CLI 和 HTTP 接口，可以接进自己的自动化流程
