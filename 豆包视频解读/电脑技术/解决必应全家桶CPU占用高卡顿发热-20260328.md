# 解决必应全家桶导致电脑卡顿发热、CPU 占用高

Windows 系统捆绑的"必应全家桶"导致电脑卡顿、发热问题及解决步骤。

---

## 问题根源

微软必应捆绑应用及 Edge 设置占用系统资源：
- **预装应用**：天气、新闻、财经、日历等
- **Edge 浏览器**：MSN 智能搜索、快速链接、小部件、天气等推广内容
- **影响**：CPU 占用率飙升（最高可使 CPU 温度提高 30 度）、风扇狂转

## 解决步骤

### 1. 卸载必应相关应用
- 打开 Windows 开始菜单
- 分别搜索"天气""新闻""财经""日历"
- 对这些应用右键选择**卸载**

### 2. 优化 Edge 浏览器设置
- 打开 Edge 浏览器，进入"页面设置"
- 关闭以下功能：
  - MSN 智能搜索（预览）
  - 快速链接
  - 显示内容
  - 显示小部件
  - 显示天气
  - 网站导航
- 去掉浏览器背景（清理烦人的导航和推广内容）

## 优化效果

- 降低 CPU 占用
- 减少发热与风扇转速
- 提升系统流畅度
