# 免费 AI 知识库工具教学 — Obsidian + Claude Code

60 万人浏览的超强免费 AI 知识库搭建教程。

---

## 一、工具介绍

- **Obsidian**：本地 Markdown 笔记软件，基础功能免费，支持丰富的主题和插件，可构建知识网络（内链接功能），仅同步功能需付费（可通过 iCloud 等替代）
- **Claude Code**：AI 工具，通过 Claudian 插件与 Obsidian 结合实现高效的文档生成与交互

## 二、核心操作教学

### 1. Obsidian 安装与基础
- 从官网下载安装
- 通过"新建仓库"创建本地文件夹管理笔记
- 支持 Markdown 格式编辑，界面可渲染格式

### 2. 与 Claude Code 联动
- **Claudian 插件安装**：从 GitHub 下载文件并手动配置到 Obsidian `.obsidian/plugins` 目录
- 若 GitHub 下载失败，可替换为国内镜像站（如 Gitee 搜索"Obsidian Claudian 插件"）
- 需在 Claude 官网获取 API Key（免费额度足够个人使用）
- 插件设置页选择模型（Claude 3 Sonnet 平衡速度与能力）

### 3. 界面与交互
- 左侧文件目录、中间编辑区、右侧 AI 对话区
- 可直接对当前文档提问，AI 自动读取内容并生成回复
- 支持模型和模式切换

## 三、特色功能

- **知识网络（内链接）**：在文档间建立关联，形成类似人脑思维的网状知识结构
- **标签分类**：用 `#标签` 分类，Obsidian 自动生成标签云，方便 AI 快速筛选
- **模板插件（Templater）**：预设笔记格式（会议纪要、技术文档模板）

## 四、AI 交互实用指令

**单篇文档：**
- "总结本文核心观点"
- "将内容拆分为行动步骤"
- "用 [场景] 举例延伸"

**跨文档关联：**
- "整合标签 #XXX 下的所有笔记，梳理 [主题] 流程"

## 五、进阶功能

- **本地文件批量处理**：通过 Advanced Tables 插件导入 Excel/CSV 数据，AI 直接读取分析
- **多模态支持**：安装 Image Toolkit 插件，AI 可识别图片内容
- **同步方案**：iCloud Drive（苹果）或坚果云（跨平台）替代付费 Obsidian Sync

## 六、优势总结

- 本地文件 + Markdown 格式，方便 AI 读取和数据迁移
- 操作界面清晰，兼具文档编辑与 AI 交互
- 节省 Token 且效率高
