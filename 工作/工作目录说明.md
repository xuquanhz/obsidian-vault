## 分类说明

| 文件夹 | 主要内容 | 更新频率 |
|:--|:--|:--:|
| **公司信息** | 公司工商、园区档案、企业名录、资料索引 | 不定期 |
| **公司制度** | 公司30+项管理制度，按类别整理 | 不定期更新 |
| **集团制度** | 交投集团制度文件 | 不定期 |
| **集团系统的合同模板** | 集团合同模板（租赁、底商、写字楼等） | 按需 |
| **工作文件** | 月度计划/报表、调研报告 | 每月 |
| **会议纪要** | 腾讯会议纪要（AI智能纪要提取，含索引） | 按需 |
| **资产公司上会** | 党委会上会材料（干部任免、专项方案） | 按需 |
| **集约化采购** | 集团员工福利及办公用品集采专项 | 按项目 |
| **党建** | 党建学习资料 | 不定期 |
| **年度审计报告** | 历年审计报告PDF存档 | 每年 |
| **工程合同** | 工程施工、装修等合同 | 按项目 |
| **租赁合同** | 房屋场地租赁合同（含26年合同年度档案） | 按项目 |
| **其他合同** | 日常服务类合同 | 按需 |
| **岗位廉洁风险自查** | 年度廉洁风险自查材料 | 每年 |
| **西站90地块** | 项目航拍图、红线图、区域介绍 | 按项目 |
| **材料** | 专项实施方案、招标文件等 | 按需 |

## 使用提示

- **制度文件** 已全部转为 Markdown 笔记（docx/doc 原件保留）
- **公司制度 vs 集团制度**：公司制度在 `公司制度/`，集团发布制度在 `集团制度/`
- **合同文件** 文件名包含签约日期或合同编号，方便检索
- **年度审计报告** 按年份命名，可快速定位
- **上会材料** 按日期命名，与公司大事时间线对应
- **会议纪要** 由腾讯会议接口自动提取，经人工审阅后入库；无官方参会名单，人名均为纪要提及
- 搜索关键词可用 `搜索：` 快速定位相关文件
