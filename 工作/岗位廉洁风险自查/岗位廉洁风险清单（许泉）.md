岗位廉洁风险清单
岗位：董事长、总经理      填报人：许泉       责任领导（签字）:
**备注:** 1.议事决策类：党委（党组）议事规则、“三重一大”事项决策、主要负责人“五不直接分管”和“末位表态”等方面存在的风险点；2.权力运行类：人、财、物管理等重点岗位和流程审批等关键环节方面存在的风险点；3.制度机制类：制度设计、制度执行、内部管理、机制建设方面存在的风险点；4.工作流程类：工作程序、业务流程等方面存在的风险点；5.岗位履职类：行使岗位权力、履行工作职责过程中存在的风险点；6.纪律作风类型：贯彻上级重大决策部署、执行中央八项规定精神、作风效能、与管理服务对象交往等方面存在的风险点。

### Table 1

| 排查类别 | 主要廉洁风险 | 风险防控措施 |
| --- | --- | --- |
| 议事决策类 | 在公司经营班子会议中可能存在不按规定履行集体决策程序，擅自拍板决定的风险。 | 会议中执行集体决策原则，严格按照“末位表态”流程进行，安排专人记录并归档会议纪要。 |
| 权力运行类 | 在园区工程招标过程中，可能存在对投标人资格审核、评标环节把控不够严谨，引发公平性争议的风险。 | 严格遵照公司采购管理相关制度执行，坚决执行集体决策制度，自觉接受纪检部门监督。 |
| 制度机制类 | 公司在园区运营管理中可能存在对上级制度理解不到位的情况，公司制度执行不到位的情况。 | 建立上级制度解读机制，邀请上级部门专家或内部业务骨干开展专题培训，定期组织制度执行情况自查与复盘，对执行偏差及时纠正。 |
| 工作流程类 | 无 | 无 |
| 岗位履职类 | 对下属部门工程招标、招商租赁、园区运营等重点业务指导监督不够到位，未能及时发现并纠正工作偏差的风险。 | 建立重点业务监管台账，定期对工程招标、招商租赁等工作开展专项督查，发现问题严肃问责。 |
| 岗位履职类 | 可能存在业务发展变化未及时更新完善相关制度，导致制度与实际工作脱节，无法有效防控廉洁风险的风险。 | 建立制度动态更新机制，每年根据业务发展、政策变化等情况，对相关制度进行评估，需要更新的及时启动修订程序。 |
| 纪律作风类 | 园区在运营过程中可能存在工作效能不够扎实，对园区运营、招商租赁、超市运营等重点工作推进统筹不力，效率和工作质量不高的风险。 | 建立重点工作台账，明确园区运营、招商合作等任务的责任分工、时间节点，定期调度推进情况，对滞后事项及时督办。 |
