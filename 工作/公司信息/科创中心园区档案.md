# 杭州交投科创中心 · 园区档案

> [!info] 园区定位
> 位于杭州市高新区（滨江）物联网小镇核心区，聚焦**智慧交通、新基建、物联网/互联网**三大核心产业定位的国企产业园区。

---

## 一、园区基本指标

| 指标 | 数值 |
|:--|:--|
| **项目名称** | 杭州交投科创中心（曾用名：交投智慧园） |
| **地址** | 杭州市滨江区月明路33号（东临风情大道，西依协同路，北靠月明路） |
| **总投资** | 约 4.6 亿元 |
| **占地面积** | 30 亩 |
| **总建筑面积** | 8.3万㎡（约84,112㎡，另有84,177㎡说法） |
| **地上建筑面积** | 5.4万㎡ |
| **地下建筑面积** | 2.8万㎡（地下两层停车库） |
| **办公区域面积** | 约 4.5万㎡ |
| **商业配套面积** | 约 0.5万㎡ |
| **机动车停车位** | 669 个（地上55、地下614，含新能源充电桩车位70余个） |
| **开工时间** | 2017年12月 |
| **运营时间** | 2020年10月正式投入运营 |
| **建筑工艺** | 滨江区首个采用装配式建造工艺的产业项目 |

## 五、租金与配套（招商参考）

| 项目 | 内容 |
|:--|:--|
| **租金** | 约 1.4-2.7 元/㎡/天（市场平台统计均价约2.3元） |
| **物业费** | 约 8.5-8.6 元/㎡/月 |
| **得房率** | 约 70% |
| **最短租期** | 1-2 年 |
| **付款方式** | 多为付六押二 |
| **车位费** | 400 元/月 |

**交通配套：**
- 地铁7号线兴议站约881米、6号线星民站约1公里、1号线江陵路站约1.5公里
- 园区有直达地铁接驳巴士
- 500米内12个公交站

**园区配套：**
- 约967㎡员工食堂及独立包厢
- 24小时无人超市、连锁咖啡、简餐
- 共享打印中心、商务中心
- 3个专业会议室（4K投影、远程视频会议）
- 健身房、羽毛球馆、便利店、杭州书房
- 1500㎡国资国企党群服务中心、暖企小站

## 六、发展规划（做精做优实施方案要点）

| 时间 | 目标 |
|:--|:--|
| 2026年底 | 落地"AI哨兵"；完成品牌体系梳理 |
| 2027年 | 投用1台无人清扫车；完成ISO管理体系认证；科技类企业占比超70%；储备1个轻资产项目 |
| 2028年 | 建成智慧运营"驾驶舱"；试行无人驾驶接驳车；完成省级孵化器申报；落地1个创新研究院/联合实验室；出租率稳定92%+ |
| 2027-2028 | 物业服务团队切换至交投物业公司 |
