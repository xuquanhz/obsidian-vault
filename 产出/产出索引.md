# 📤 产出索引

> 按时间倒序的产出总表。每产出一次，自动出现在这里。

## 全部产出

```dataview
TABLE file.folder AS "分类", updated AS "更新日", status AS "状态"
FROM "产出"
WHERE file.name != "产出说明" AND file.name != "产出索引"
SORT file.mtime DESC
```

## 待回流产出（尚未反写回知识条目）

```dataview
LIST
FROM "产出"
WHERE file.name != "产出说明" AND file.name != "产出索引"
  AND (length(file.outlinks) = 0 OR !regextest("已回流", file.content))
SORT file.mtime DESC
```

> 判断标准：正文里含"已回流"标记，**且**已建立至少一条反向链接，才算完成回流。
