# 📤 产出索引

> 按时间倒序的产出总表。每产出一次，自动出现在这里。

## 全部产出

```dataview
TABLE file.folder AS "分类", updated AS "更新日", status AS "状态"
FROM "产出"
WHERE file.name != "产出说明" AND file.name != "产出索引"
SORT file.mtime DESC
```

## 待回流产出（尚无反向链接）

```dataview
LIST
FROM "产出"
WHERE file.name != "产出说明" AND file.name != "产出索引"
  AND length(file.outlinks) = 0
SORT file.mtime DESC
```

> 回流标准：产出正文里至少建立一条指向知识条目 / 源文件的 `[[ ]]` 链接；核心结论同时反写回原条目。
